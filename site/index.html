Link-only workflow

The user should not need to understand the tool.

1

Paste the link

The user gives an AI coding agent the Vibe-Guard repository link.

2

Agent applies it

The agent installs or refreshes guardrails in the current project.

3

Work continues safely

Safe fixes run first, risky work stops for approval, and the original request continues.

Default checks

Built for common AI coding mistakes.

S

Secrets

Detects likely hard-coded secrets and never prints the values.

E

Env safety

Protects local env files and keeps examples value-free.

D

Data risk

Flags destructive scripts, migrations, and production actions.

C

Cost risk

Warns when paid APIs or quota-based services need guardrails.
