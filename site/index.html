Safety guardrails

The checks are practical: secrets, cost, data, deployment, and Git.

Secret handling

Detects likely hard-coded secrets without printing the value. Simple JS, TS, and Python assignments can be moved into an ignored env file.

Env file hygiene

Keeps runtime env files ignored and keeps shareable env templates value-free.

Data-loss pause

Flags database resets, destructive scripts, and shell commands that can remove data before the agent runs them.

Cost-aware architecture

Pushes repeated API, provider, and model calls toward shared server-side helpers, caching, batching, and rate limits before adding paid services.

Repository checks

Reviews the remote, repository visibility, and changed files before commit or push, with extra care for public or unknown-visibility repos.

Server boundary

Keeps provider keys, database URLs, service-role keys, and webhook secrets on the server side.
